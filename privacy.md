The Entergy App is a student-built application created for an academic project focused on utility vegetation management, infrastructure analysis, and operational planning. This policy explains what data is collected, how it is used, and how it is protected.

1. Information We Collect

The Entergy App may collect:

Account information (such as username or email, if login is used)

App usage data (tasks completed, schedules, project progress, team member names)

Device and browser information

The Entergy App does not collect:

Payment information

Government ID numbers

Financial account numbers

Biometric data

Phone contacts, photos, or microphone recordings

2. How Information Is Used

Collected data is used only to:

Operate the application

Save user progress

Display project dashboards

Improve app stability and functionality

Support class demonstrations and evaluations

Data is never sold, rented, or shared for marketing purposes.

3. Data Storage

Data is stored using standard web storage, databases, or cloud hosting platforms.
This project is intended for educational use, not public commercial deployment.

Reasonable security practices are used to protect stored data.

4. Cookies and Local Storage

The Entergy App may use cookies or browser storage to:

Keep users logged in

Remember preferences

Save app state

No advertising or tracking cookies are used.

5. Third-Party Services

The app may use third-party services such as:

Web hosting providers

Analytics tools for anonymous performance tracking

These services only receive the minimum data required to function.
